# R13-F: n8n triggers inside Crews

Files: `stack/crew-service/main.py` (`POST /crews/trigger`), `test_trigger.py`; `src-tauri/src/commands/n8n_status.rs` (`n8n_status`), `src-console/bridge.ts`, `src-console/crews/n8n.ts`, `liveWiring.test.ts`; `stack/n8n/examples/` (inactive example + README); `CREW_TRIGGER_SECRET` comes from `.env.crew` via env_file (unset = disabled).

## Acceptance and evidence
- Unauthenticated trigger -> 403 (no secret, missing/bad/stale/replayed signature, oversize body); signed trigger creates a run via `_launch` (visible in `crew_list`): `test_trigger.py` (9 passed). HMAC-SHA256 over `<timestamp>.<raw body>`, bytes compared with `hmac.compare_digest`; separate secret, so n8n never holds `X-Crew-Token`.
- `n8n_status`: connected from `/healthz`; workflow count and failures7d only with an optional 0600 `n8n_api_key` file in app data (no secret in the repo), else `null`. GET only, loopback only (test asserts no POST/PUT/DELETE/PATCH). Rust tests: 4.
- Adapter: `liveN8nAdapter` wires `n8n()` only when connected AND both counts are known; otherwise it stays unwired (shape has numeric counts). Touch to design-owned `CrewsScreen.tsx`: three logic lines (hooks chained after `useLiveApprovals`), no markup/class change.
- No n8n workflow was created, changed or deleted; the example JSON is `active:false` and not imported.

## Security review re-run (2026-11-12)
- Fixed: replay bypass. The HMAC check compared `signature.strip()` but the replay cache keyed on the raw header, so the same signature with a trailing space/tab replayed. Now one normalized value is checked and stored. `test_replay_with_whitespace_around_the_signature_is_403` (failed before, passes after).
- Fixed: a triggered run gets no files/terminal grant (see D-1110i).
- Fixed: compose listed `CREW_TRIGGER_SECRET: ${CREW_TRIGGER_SECRET:-}` under `environment:`, which overrides `env_file` (.env.crew) with a blank, so the trigger could never be enabled the documented way. Removed; it comes from `.env.crew` only.
- Open (TAISUN / follow-up): `scripts/sync-crew-env.sh` rewrites `.env.crew` with only `CREW_INGRESS_SECRET`, so a hand-added `CREW_TRIGGER_SECRET` is dropped at the next sync (fails closed: trigger 403). Teach the script to carry it before enabling the trigger.
