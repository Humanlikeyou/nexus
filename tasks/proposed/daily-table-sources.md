## Shared facts

## Suggested day-key rule
1. Day key = `YYYY-MM-DD` in fixed UTC+9 (`local_store::jst()`), never `chrono::Local`.
2. Epoch-seconds sources (NOOP `workout.startTs`): `DateTime::from_timestamp(ts)` -> `.with_timezone(&jst())` -> `.date_naive()`.
3. RFC3339 sources (Muse `start`, Hemi-Sync `startedAt`, roadmap `doneAt`): parse, convert to JST, take date (same as patterns.rs:951-958). Do NOT use `.take(10)`.
4. Already-dated sources keep their label (NOOP `dailyMetric.day`, check-in `day`, take-log `day`, follow-up `done`): trust the string, record it as "source-labelled day".
5. Row key rule for NOOP: use the row's own `day`, no shifting; store a `source_ref` (e.g. `noop:sleep_total_min:<day>` like patterns.rs:1122) per cell for traceability.
6. Missing = SQL NULL, never 0. Minutes columns: NULL when no rows, else the sum.
