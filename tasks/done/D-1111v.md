## Criteria and evidence
1. Decisions log (`decisions_log.rs`: decisions_list / append / undo / add_outcome; `decisions/decisions.json`)
   - Separate from the ledger; the module has no ledger/network code (test greps its source) and a test shows `business/ledger.json` is byte-identical after append.
   - Record: choice, JST time, proposer, source link, outcome later. Undo only inside 8 s (7.9 s ok, 8.001 s refused); an outcome fills once and never rewrites the choice. Evidence: 5 Rust tests (`decisions_log::tests`).
2. Life dates (`life_dates.rs`: life_date_upsert / list / delete / preview; `life/dates.json`)
   - Reminders computed at 90/30/7 days when listed (test: 2027-09-14 -> 06-16, 08-15, 09-07); no timer, no notification. Windows: 7-day rung open 7 days out to the date; 90/30 open on the reminder day + 2 days.
   - Preview never guesses: missing year/day, or a day that does not exist, is a question; business dates point to Enterprise. 5 Rust tests.
3. Adds, one write path (`adds.rs`: add_preview / add_save / add_undo / add_history), `via` typed|voice|chat
   - Reuses goals.json (habit goals), `~/.openclaw/workspace/TASKS.md`, `CONTENT-PIPELINE.md` (what read_tasks / read_content_pipeline read) and the dates store. No parallel store.
   - Venture id: `#venture:<id>` tag, matched only against ventures in the business ledger; `venture` field added to TaskItem / ContentPipelineItem (openclaw.rs, 3 small edits) and the TS types.
   - preview writes nothing (test); save only from a validated payload of the same kind; undo within 8 s removes the item and its history row; history capped at 200; files 0600, temp+rename, 1 MiB caps. 5 Rust tests.
4. Check-in (`checkin.rs`: checkin_save / checkin_list): text only, mood/energy 1-5, tags <= 8, text <= 2000; test asserts no audio field. 2 Rust tests.
5. Needs you today (`needs_you.rs`: needs_you_list): read-only pointers over to-dos, dates (windows), check-in, decisions (ledger waiting minus log), crew (crew_health + crew_list_approvals "pending"). Per-source ok/failed/unwired. Tests: pointer keys only; source contains no writer or crew_decide call. 4 Rust tests. Amara's own action approvals stay a UI pointer from the snapshot.

- Routes: old -> new redirects already exist (`VIEW_REDIRECTS` / `canonicalRoute`) and `src-console/app/routes.test.ts` covers them; no change needed.
