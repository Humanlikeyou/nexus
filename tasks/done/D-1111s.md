## Deviation for Taisun
Handoff asks Argon2id/scrypt + AEAD; neither crate is available offline. Used ring 0.17: PBKDF2-HMAC-SHA256, 600,000 iterations, random 16-byte salt, AES-256-GCM, random 12-byte nonce, header (magic, version, iterations, salt, nonce) as AAD. PBKDF2 is not memory-hard: choose a long passphrase. Version byte allows a later KDF swap. Other choices: key file lives in `~/Amara Backups/amara-n8n.key` (`NEXUS_KEY_FILE_DIR` overrides, used for dev); unlock refuses (`key_exists`) rather than overwrite a different n8n key; secret `n8n_encryption_key` is the Keychain item `com.taisun.nexus.n8n_encryption_key` (no existing item was found in the repo; if the live n8n key is stored under another service name, it needs a one-time import).
Keychain items use account `amara`.
