# 0011: System map in Settings › Services (Taisun, 2026-11-12, in session)

His ask: "a map showing me the back end and front end of this application and just a quick status update check": every pathway data travels, a steady green dot when it flows, a blinking red dot when it's broken.

His answers:
1. **Where:** the top of Settings › Services.
2. **Off on purpose** (Claude tier off, Telegram sends paused, OpenClaw removed, navy mode, outbound disabled): a steady **grey** dot. Blinking red is reserved for real breaks.
3. **Refresh:** live, every 10 s while the map is on screen; stops when he leaves.
4. **Click a dot:** a plain-English panel: what the path carries, when it last worked, what's wrong, and the one usual fix.

Constraints: checks are loopback/local only (health endpoints, file/socket presence, last-success timestamps); no new outbound host; never a secret, token or path in the panel; checks never write, restart or change anything. Reduced motion: the red dot doesn't blink (a static red ring instead). Design Lead builds the map UI; the backend provides `system_map_status`.
