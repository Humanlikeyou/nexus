## Wiring order (Claude)
1. **Secrets status/set** — `secrets_status(): { name, label, set }[]`, `secret_set(name, value)` (zeroize after the Keychain write; no command ever returns a value). Unblocks Notifications keys, Keys on this Mac and the restore re-enter list. Sentinel test across logs, kv, backups, IPC.
2. **n8n key file (passphrase backend)** — `key_file_status(): { made, made_at?, where }`, `key_file_make(passphrase)`: export `N8N_ENCRYPTION_KEY` from the Keychain, encrypt with a key derived from the passphrase (Argon2id/scrypt + AEAD), write `amara-n8n.key` (0600) **outside** the backup dir, drop the passphrase from memory. Restore side: `key_file_unlock(path, passphrase)` puts the key back in the Keychain byte-identical, or returns `wrong_passphrase` / `not_found`. The passphrase is never stored, logged or returned. Backups must never contain the key file (archive scan test).
3. **Backup settings + run** — extend `packager.rs`: `backup_settings` `{ nightly: true, at: "03:00", dir: "~/Amara Backups", keep: 14, before_update: true, skip_on_battery_below: 20 }`, `backup_now()` progress events, `backup_list()`, `restore_preview(file)`, `restore(file)` (always saves current data first, then stop → restore → verify → restart; returns missing key names). Excludes every Keychain item and the key file. 0600 archives in a 0700 dir.
4. **Services supervisor** — `services_status()`, `service_events`, `service_log_tail` (redacted), `service_restart/start/stop` (loopback-only, drain first, never change images/versions), `services_summary()` for the sidebar. Rows as in the mock (no OpenClaw). "Health sync · reader" and "Health sync" are `built_in` Amara services.
5. **WHOOP ownership + transition lock** — `whoop_status(): { owner: amara|legacy|none, … }`. While `owner = legacy` (the old health app still holds the strap) every strap action returns `locked_by_legacy` and the UI shows the takeover notice. `whoop_take_over()`: ask first, release the other app **gracefully** (never kill -9), copy and verify the health store, take the single-owner lock, keep the old copy read-only 30 days (deleted only with Taisun's OK). After that `owner = amara` and the notice is gone for good. Then `whoop_sync_now`, `whoop_buzz`, `whoop_pair_start/events`, `whoop_forget` (WHOOP 4 only).
6. **Telegram relay** — settings are only `{ enabled, kinds: Record<kind, bool> }` (no quiet hours, no rate limit). Token + chat in the Keychain (`com.taisun.nexus.telegram.*`), UI sees `set` only. Local light-tier wording, numbers checked against the source row. `notify_preview()` sends nothing; Send Test confirms first and never sends under `NEXUS_OUTBOUND_DISABLED=1`.
7. **Updates** — `update_status()` (no invented versions: `available.version` comes from the signed manifest), `update_check()`, `update_install_now()`, prefs `auto_update`, `check_daily`. Install order: backup → wait for crews/Muse → stop → swap → start → health check → roll back on failure. Needs Developer ID + updater key first.
8. **First-run** — `setup_done()`, `setup_reset()`, `system_profile()`, `model_tiers()` (signed manifest; names need Taisun), `model_download(tier)` events, `services_start_all()`, `keychain_import_review()` (names only).
