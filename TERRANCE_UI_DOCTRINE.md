# Amara OS Visual Doctrine

The legacy card, tile, bento, widget, and admin-dashboard aesthetic is permanently deprecated.

## Never Use

- Square section tiles or equal block grids
- Bento layouts or generic dashboard cards
- Heavy rectangular containers or bordered widget boxes
- Basic SaaS admin patterns
- A left sidebar paired with a card grid
- Old visual structures preserved for implementation convenience

## Always Favor

- A continuous cinematic command surface
- Asymmetric, layered holographic composition
- Boundaryless translucent light fields
- Radial systems and biometric readouts
- Signal streams, waveforms, scanning bands, and coordinate systems
- Neural and light-node motifs
- Curved traces, masks, depth, glow, and restrained motion
- High operational readability throughout

When a UI region begins to resemble a card, tile, widget, or bordered rectangle, remove its boundary and rebuild it as an integrated system layer. Preserve data and behavior, never the deprecated visual structure.
